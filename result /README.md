# Final Experimental Results

This directory contains the final experimental results reported throughout the dissertation.

Unlike the `Output/` directory, which stores intermediate outputs generated during notebook execution, this directory contains the final summary tables and comparison results supporting the dissertation conclusions.

## Files

| File | Description |
|------|-------------|
| `final_comparison_table.csv` | Overall comparison between the baseline confidence estimator and the proposed multi-signal confidence estimation framework. |
| `roc_auc_comparison_results.csv` | Comparative ROC-AUC performance of the evaluated confidence estimation methods. |
| `final_calibration_comparison.csv` | Final calibration comparison using Expected Calibration Error (ECE). |
| `overall_method_ranking.csv` | Ranking of confidence estimation methods across all evaluation metrics. |
| `key_findings_summary.csv` | Summary of the principal experimental findings reported in the dissertation. |

## Reproducibility

The files in this directory are generated by the final comparative evaluation notebook (`05_final_comparative_evaluation.ipynb`). They correspond directly to the quantitative results reported throughout the dissertation and provide the final performance summaries used to evaluate the proposed multi-signal confidence estimation framework against the baseline confidence estimator.
