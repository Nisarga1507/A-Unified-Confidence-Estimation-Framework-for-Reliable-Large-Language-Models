 # Experimental Notebooks

This directory contains the five Jupyter notebooks implementing the complete experimental workflow of the dissertation.

| Notebook | Description |
|----------|-------------|
| **01_baseline_confidence_estimation.ipynb** | Generates baseline predictions and confidence scores using Mistral-7B-Instruct on the TruthfulQA benchmark. |
| **02_selective_prediction_analysis.ipynb** | Evaluates selective prediction behaviour using confidence thresholds and risk–coverage analysis. |
| **03_option_likelihood_signal_analysis.ipynb** | Extracts and analyses uncertainty signals derived from option likelihood distributions, including entropy, normalised entropy, margin score and probability gap. |
| **04_multi_signal_confidence_estimation.ipynb** | Constructs the multi-signal confidence estimator using complementary uncertainty signals and evaluates calibration improvements. |
| **05_final_comparative_evaluation.ipynb** | Performs the final comparative evaluation between the baseline and multi-signal confidence estimators using ROC-AUC, ECE, AURC and bootstrap statistical analysis. |

## Execution Order

Run the notebooks sequentially from **Notebook 1** to **Notebook 5**, as each stage builds on outputs generated by the previous notebook.
