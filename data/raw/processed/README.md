# Processed Data

This directory contains the intermediate datasets generated throughout the dissertation workflow.

The processed datasets are produced sequentially by the experimental notebooks and serve as inputs for subsequent stages of the confidence estimation framework.

## Generated Outputs

The processed data include:

- Baseline model predictions
- Confidence scores
- Option likelihood probabilities
- Extracted uncertainty signals
- Standardised feature values
- Multi-signal confidence estimates
- Intermediate evaluation results

## Workflow

The processed datasets are generated in the following order:

1. Notebook 1 – Baseline Confidence Estimation
2. Notebook 2 – Baseline Confidence Evaluation
3. Notebook 3 – Option Likelihood Signal Analysis
4. Notebook 4 – Multi-Signal Confidence Estimation
5. Notebook 5 – Final Comparative Evaluation

These files are automatically generated during notebook execution and should not be edited manually.
