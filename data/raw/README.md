# Raw Dataset

This directory contains the original dataset used throughout this dissertation.

## Dataset

**TruthfulQA Multiple-Choice Benchmark**

- **File:** `TruthfulQA.csv`
- **Format:** CSV
- **Task:** Multiple-choice question answering
- **Purpose:** Benchmark dataset for evaluating confidence estimation in Large Language Models (LLMs)

## Usage

The dataset is used as the input for:

- Notebook 1 – Baseline Confidence Estimation

All preprocessing, confidence estimation and feature extraction are performed within the experimental notebooks.

The original dataset is stored in its raw format and is not modified.

## Reference

Lin, S., Hilton, J., & Evans, O. (2022). *TruthfulQA: Measuring How Models Mimic Human Falsehoods*. Proceedings of the 60th Annual Meeting of the Association for Computational Linguistics (ACL).
