# Experimental Outputs

This directory contains all intermediate outputs generated throughout the dissertation experiments.

Each subdirectory corresponds to one notebook in the experimental workflow and stores the outputs required for subsequent stages of the analysis.

| Folder | Contents |
|----------|----------|
| `01_baseline_confidence_analysis/` | Baseline model predictions, confidence estimates and generated evaluation data. |
| `02_selective_prediction_analysis/` | Coverage, risk, AURC and selective prediction outputs. |
| `03_option_likelihood_signal_analysis/` | Extracted option likelihood distributions, uncertainty signals and statistical summaries. |
| `04_multi_signal_confidence_estimation/` | Multi-signal confidence estimates, transformed features and fusion outputs. |
| `05_final_comparative_evaluation/` | Final evaluation metrics, bootstrap analysis, comparative summaries and statistical results. |

The outputs stored in this directory are generated automatically during notebook execution and provide the intermediate data required to reproduce the complete experimental workflow.
