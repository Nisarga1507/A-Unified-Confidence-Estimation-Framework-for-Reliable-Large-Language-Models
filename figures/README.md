# Figures

This directory contains all visualisations generated throughout the dissertation experiments.

Each subdirectory corresponds to one notebook in the experimental workflow.

| Folder | Contents |
|----------|----------|
| `01_baseline_confidence/` | Baseline confidence distributions, prediction statistics and initial evaluation figures. |
| `02_selective_prediction/` | Coverage–accuracy curves, risk–coverage curves and selective prediction visualisations. |
| `03_option_likelihood/` | Option likelihood distributions, entropy analysis, correlation heatmaps and feature comparison figures. |
| `04_multi_signal_confidence/` | Multi-signal confidence distributions, calibration plots, reliability diagrams and uncertainty analysis. |
| `05_comparative_evaluation/` | Final comparison figures including ROC curves, calibration comparisons, AURC analysis and statistical evaluation plots. |

All figures are generated automatically during notebook execution and are included in the dissertation to support the analysis, interpretation and comparison of the experimental results.
